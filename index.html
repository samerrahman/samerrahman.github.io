Projects

Lung Sound Classification (PCEN)

Biomedical acoustic engineering and machine learning research developing an automated diagnostic classification system for respiratory pathology. Uses Per-Channel Energy Normalization (PCEN) time-frequency representations to suppress ambient hospital noise and detect wheezes, crackles, and disease signatures with deep convolutional neural networks.

View on GitHub

Unsupervised SEAL

A machine learning project that teaches models to find useful patterns in complex data on their own, without needing people to label examples first. It explores how models organize what they learn internally, how they group similar data together, and how comparing examples to each other can help them build better understanding with little human guidance.

View on GitHub

WhisperTeX: Speech-to-Written LaTeX for Mac

A native macOS application and CLI that lets you dictate mathematics in natural English and compiles it into precision LaTeX—automatically pasting directly wherever your cursor is blinking across Overleaf, Notion, Google Docs, or VS Code.
